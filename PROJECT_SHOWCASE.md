# Bridal Bliss Project Showcase

## Overview

Bridal Bliss is a polished Flask application designed for bridal styling marketplaces, combining product shopping, salon discovery, booking management, and AI-powered bridal recommendations.

## Showcase Highlights

- Personalized bridal experience for brides with profile settings, wishlist, and budget planning
- Salon owner workspace for managing services, appointments, and portfolio galleries
- Admin moderation dashboard for approving salons, managing products, and overseeing platform activity
- AI recommendation engine for products and salons, with budget planning and bridal look matching
- REST API layer for products, looks, bookings, wishlist, and orders

## User Journeys

### Bride

- Sign up and create a bridal profile
- Browse bridal looks and product catalog
- Add items to wishlist and cart
- Simulate checkout and place orders
- Book salon appointments and track status
- Receive notifications for bookings and orders

### Salon Owner

- Register a salon profile and upload portfolio content
- Add and manage salon services
- View booking requests and update appointment status
- Track salon revenue and pending bookings

### Admin

- Approve or reject salon profiles
- Create catalog products and bridal looks
- Monitor platform metrics and user activity
