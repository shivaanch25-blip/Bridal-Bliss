# Resume Project Summary

## Bridal Bliss

A role-based bridal marketplace web application built with Flask, SQLAlchemy, and Jinja2 templates.

### Key Responsibilities

- Designed and implemented a modular Flask architecture with blueprints for authentication, shopping, studio, salon owner, admin, and API features.
- Built a SQLAlchemy relational data model supporting users, salons, products, bridal looks, bookings, orders, wishlists, notifications, and audit logs.
- Implemented role-based access control for brides, salon owners, and admin users.
- Added AI-driven recommendation helpers for product matching, salon ranking, and budget planning.
- Created production-ready deployment configuration with Gunicorn, environment variable support, and Render compatibility.
- Wrote documentation for system architecture, API reference, database schema, deployment, testing, and portfolio showcase.

### Tech Stack

- Python 3 / Flask 3
- Flask-SQLAlchemy / SQLAlchemy
- Flask-Login
- Jinja2 templates
- SQLite / configurable database URI
- Gunicorn
- Pytest

### Impact

- Delivered a polished bridal styling platform with end-to-end user journeys for product purchase, salon booking, and bridal planning.
- Improved developer onboarding with a clear documentation set and deployment guide.
- Enabled future production deployment with environment-based configuration and a standard Procfile.

### Notable Features

- Multi-role dashboards for brides, salon owners, and administrators
- AI-assisted bridal look and product recommendations
- Wishlist, cart, checkout, and order tracking
- Salon portfolio management and approval workflows
- Built-in route audit script and testing guide
